# R03 user blind playtest

| Build | User feedback |
|---|---|
| A | "It's fine." Didn't understand what Borrowed Second does; didn't notice it doing anything. Attack + confirmation flow annoying and unintuitive. HP bars/side panel take far too much space vs the map. Attack ranges and stats poorly communicated. |
| B | Much better than A. Borrowed Second still a bit confusing but did roughly what was expected (got a second turn). Attack ranges still not communicated well. Confirm button higher up (no scrolling) is better, but prefers NO confirmation step at all — misclicks are what the Turnwheel is for. Units in a confined scrollable sidebar box much nicer, though still too present. |
| C | Worse than B, better than A. Confirmation still there and placed away from the attack button (annoying). Borrowed Second works. Strange UI choices about which information is shown and which isn't (others had similar problems). |
| D | Harder to judge: similar to B, maybe a bit worse overall but better in some ways. |
| **Verdict** | Re-checked B vs D: D put in significantly more effort for a similar result, maybe a tiny bit better but not in every way. **Final: B > D > C > A. B is the base.** |
