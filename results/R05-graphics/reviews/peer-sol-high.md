**A.** Strongest reusable architecture: pure visual recipes, shared SVG/Pixi shapes, cached terrain, named status badges, kernel-derived paths, sequential strike timelines and demand-driven rendering. Screens, settings and screenshot tour are extensive; tests cover contrast, class variation, timelines, pointer scaling and full/reduced state-hash equivalence. No performance measurement was found. Defects: the replay ordinal never resets on rewind/restart, suppressing repeated enemy phases ([App.tsx:140](A/game/src/renderer/App.tsx:140)). The phase-banner effect depends on the whole visual state: selecting a unit during a banner clears its timer, then the unchanged phase signature returns early, leaving the banner stuck ([App.tsx:430](A/game/src/renderer/App.tsx:430)). Skip changes the input beat to null, but existing scheduled strikes/tweens are only finished for a new non-null beat; old playback can continue over the final state ([BoardScene.ts:238](A/game/src/renderer/board/BoardScene.ts:238)). Name-based strike lookup can choose the wrong target when generated units share names ([beats.ts:74](A/game/src/presentation/beats.ts:74)).

**B.** Best replay-state handling: duplicate revisions are rejected, rewind resets the replay marker, and both sides receive exchange feedback. Retained terrain, bounded ticker, pure recipes, forecast-branch summaries, exhaustive pointer helper tests and screenshot/cadence checks provide a solid compact base. Defects: status badges sum every status into “DBT”, hiding their actual generated identity ([PixiBoard.tsx:123](B/game/src/renderer/components/PixiBoard.tsx:123)); player strike cues identify participants by nonunique display names ([presentation.ts:132](B/game/src/renderer/presentation.ts:132)). Exchange strikes are aggregated and animated together, losing initial/counter/follow-up order ([presentation.ts:138](B/game/src/renderer/presentation.ts:138)). Reduced-motion E2E checks an animation flag and unchanged movement RNG, without comparing complete full/reduced outcomes ([battle.e2e.ts:525](B/game/e2e/battle.e2e.ts:525)).

**C.** Smallest change, retaining the deterministic kernel and existing screens, but incomplete animation/accessibility work and weak new tests. Defects: motifs use only `classId`, which generation sets to weapon tag, so differently titled generated classes sharing equipment receive identical tokens ([PixiBoard.tsx:337](C/game/src/renderer/components/PixiBoard.tsx:337), [campaign.ts:632](C/game/src/rules/campaign.ts:632)). All terrain, units and labels are rebuilt on every hover; token containers are destroyed without recursively destroying their children ([PixiBoard.tsx:59](C/game/src/renderer/components/PixiBoard.tsx:59)). Combat picks the first injured unit, potentially showing the attacker's counter-damage as the initiating strike; zero-damage hits become MISS ([App.tsx:157](C/game/src/renderer/App.tsx:157)). Rewinds are animated as forward movement/deaths ([PixiBoard.tsx:635](C/game/src/renderer/components/PixiBoard.tsx:635)), and repeated enemy playback is suppressed ([App.tsx:133](C/game/src/renderer/App.tsx:133)). All statuses are labelled DBT ([PixiBoard.tsx:409](C/game/src/renderer/components/PixiBoard.tsx:409)). Settings omit text scaling; attack choreography and player path previews are largely absent. No performance measurement.

**D.** Broad screen coverage, reusable visual recipes, synthetic audio and weapon-specific effects; useful unit/terrain/path tests and a real screenshot tour. Defects: player paths are computed from post-command flags and destination occupancy, so the helper rejects them and rendering falls back to a straight segment across corners/obstacles ([PixiBoard.tsx:970](D/game/src/renderer/components/PixiBoard.tsx:970), [visuals.ts:322](D/game/src/shared/visuals.ts:322)). Hover rebuilds terrain and every token, discarding in-flight waypoints ([PixiBoard.tsx:1428](D/game/src/renderer/components/PixiBoard.tsx:1428)). Replay repeats are suppressed after rewind/restart ([App.tsx:269](D/game/src/renderer/App.tsx:269)); fixed replay timers can advance before movement/strikes finish ([App.tsx:336](D/game/src/renderer/App.tsx:336)). Reduced mode still moves floating text and labels zero-damage hits MISS ([PixiBoard.tsx:907](D/game/src/renderer/components/PixiBoard.tsx:907), [PixiBoard.tsx:1446](D/game/src/renderer/components/PixiBoard.tsx:1446)). Display-name lookup can assign strikes to the wrong same-named unit ([App.tsx:154](D/game/src/renderer/App.tsx:154)); all statuses are labelled DBT ([PixiBoard.tsx:352](D/game/src/renderer/components/PixiBoard.tsx:352)). Battle/class/equipment seed changes reroll facial identity ([visuals.ts:134](D/game/src/shared/visuals.ts:134)). No performance measurement.

**E.** Compact retained renderer, stable identity/class separation, live OS-motion handling, full/reduced hash checks, resize checks, gallery and documented foreground cadence (median 16.7 ms; not GPU stress evidence). Defects: replay ordinal remains stale after rewind/restart ([App.tsx:145](E/game/src/renderer/App.tsx:145)). Normal-speed movement can last 420 ms while replay advances at 320 ms, rebuilding pieces and cutting travel short ([PixiBoard.tsx:199](E/game/src/renderer/components/PixiBoard.tsx:199), [App.tsx:192](E/game/src/renderer/App.tsx:192)). Reduced-motion lethal targets are skipped before damage/DOWN feedback is emitted ([PixiBoard.tsx:193](E/game/src/renderer/components/PixiBoard.tsx:193)). Attacks resolve simultaneously through name-parsed logs ([PixiBoard.tsx:215](E/game/src/renderer/components/PixiBoard.tsx:215)); all statuses are labelled DBT ([PixiBoard.tsx:105](E/game/src/renderer/components/PixiBoard.tsx:105)). Empty-cell attack range is absent.

**Shared instruction issue.** All five retain identical generation plumbing that omits investigation/tool enablement ([A/GameGeneration.ts:72](A/game/sidecar/apps/server/src/game/GameGeneration.ts:72)); the identical Claude adapter supplies `--tools ""` ([A/ClaudeTextGeneration.ts:241](A/game/sidecar/apps/server/src/textGeneration/ClaudeTextGeneration.ts:241)). Native-tool choice is therefore unavailable. This is shared/inherited, not evidence of an R05 regression. Art is procedural; A bundles font licences; the others use system fonts. READMEs are updated.

**Recommendation:** A > B > E > D > C. Use A after fixing replay cancellation/identity and banner lifetime. Port B's rewind/revision safeguards and replay-state tests; E's foreground cadence/resize checks and persistent identity design; D's synthesized audio. C offers little unique engineering worth porting.
